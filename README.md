# OPIc IH Coach

OPIc 최종 목표 **IH**를 위한 개인용 Android 말하기 훈련 앱입니다. 현재 등급(기본 IM1)과 다음 시험 목표 등급(기본 IM2)은 설정에서 바꿀 수 있습니다.
"질문 듣기 → 큰 마이크 → 피드백 → 다시 말하기" 루프를 매일 끊김 없이 반복하는 것이 핵심입니다.

> 점수는 모두 **학습용 참고 점수**입니다. ACTFL/OPIc 공식 등급이나 등급 예측이 아닙니다.

---

## 1. 빠른 시작

### 설치 (Release APK)

1. GitHub Releases의 `app-release.apk`를 휴대폰으로 받습니다. 기존 Debug 설치본과 같은 키로 서명되어 있어서, 지우지 않고 덮어 설치하면 학습 기록이 유지됩니다.
2. 설치 시 "출처를 알 수 없는 앱" 허용을 요청하면 허용합니다.
3. 앱을 열면 사용자 스크립트 23문항과 개선안(승인 대기), 표현 41개, 질문 은행 81문항이 자동으로 들어갑니다.

### 직접 빌드

```bash
./gradlew :app:assembleRelease
```

```bash
./gradlew :app:testDebugUnitTest
```

- 필요 환경: JDK 17, Android SDK (compileSdk 36), Gradle wrapper 8.13 (자동 다운로드)
- `local.properties`에 `sdk.dir=C\:/Users/<you>/AppData/Local/Android/Sdk` 형식으로 SDK 경로를 넣습니다. 역슬래시(`\U...`)는 Java properties에서 이스케이프로 해석되므로 슬래시를 쓰세요.
- 결과물: `app/build/outputs/apk/release/app-release.apk` (debug 키로 서명됨, 개인 설치용)

### 실기기 설치

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

## 4. 설계 원칙과 제약

### 4.1 정직한 측정

| 측정 | 방법 | 한계 표시 |
|---|---|---|
| 무음·실발화 시간 | **음향 측정**: 녹음 모드는 PCM 20ms RMS, 실시간 모드는 `onRmsChanged` dB 타임라인 → `PauseAnalyzer` | STT와 무관한 실제 소리 기준 |
| 내용·시제·연결 | 전사 텍스트 휴리스틱 (`DiscourseAnalyzer`) | 기기 STT는 문법을 보정하고 필러를 지울 수 있다고 결과 화면에 표시 |
| 발음·억양·강세 | **측정하지 않음** | 전용 발음 평가 엔진이 없으므로 "녹음과 TTS를 직접 비교" 방식으로 대체 |

### 4.2 캡처 방식 2종

```
실시간 인식 (기본)   SpeechRecognizer ── 2초 침묵에 끊김 ──> 자동 재시작, 문장 누적
                     onRmsChanged ──> 무음 추정        (녹음 파일 없음: 마이크 동시 사용 불가)

녹음 우선           AudioRecord 16kHz PCM ──> WAV 저장 (다시 듣기, 0.75x)
                     20ms RMS ──> 정밀 무음 분석
                     텍스트: 클라우드 전사(선택, 동의 필요) 또는 없음 → 음향 지표만 표시
```

인식이 실패하면 "말한 내용 직접 입력"으로 분석을 이어 갈 수 있습니다.

### 4.3 AI는 선택, 오프라인 우선

- 기본 학습, 녹음, 분석, 복습, 알람, 모의시험은 **AI 없이 동작**합니다 (로컬 규칙 분석, "로컬 분석(AI 아님)" 라벨).
- AI는 사용자가 **키 입력 + AI 사용 + 텍스트 전송 동의**를 모두 켰을 때만 호출합니다. 실패하면 로컬 분석으로 대체하고 화면에 이유를 표시합니다.
- 키는 APK·소스에 없습니다. 설정에서 입력한 키를 Android Keystore AES-GCM으로 암호화해 저장합니다.
- 요청서는 "서버 중계 우선"이지만, 1인 사이드로드 앱이라 기기 직접 호출을 택했습니다. `AiCoach`/`Transcriber` 인터페이스 뒤에 서버 중계 구현을 추가할 수 있습니다.
- 녹음 전사도 같은 Gemini 키로 합니다. 녹음 우선 모드에서 WAV를 Gemini에 보내 필러와 문법 실수를 그대로 받아 적게 하며, **녹음 전사 켜기 + 음성 외부 전송 동의**가 모두 있어야 동작합니다.
- AI는 **Gemini 하나만** 씁니다(REST `generateContent`, 기본 모델 `gemini-3.5-flash`, 키는 `x-goog-api-key` 헤더). 설정의 '모델 목록 불러오기'로 키에서 쓸 수 있는 모델을 조회해 고를 수 있습니다.
- Gemini 무료 등급은 입력 내용이 Google 제품 개선에 쓰일 수 있고 유료 등급은 쓰이지 않습니다. 동의 문구에 이를 표시합니다. Opus/Sonnet 요청에는 서버 측 refusal fallback(`fallbacks: "default"`)을 켰습니다.

### 4.4 콘텐츠 출처 구분

| 라벨 | 의미 |
|---|---|
| 내 스크립트 (Drive) | 사용자 Google Drive `2026년 OPIc Script` 원문 |
| 앱 내장 개선안 (AI 작성) | 이 저장소를 만들 때 Claude가 작성한 IH Target/Short/Keywords. **승인 대기**로 들어가며 원본을 덮어쓰지 않음 |
| 내 기출 정리 자료(비공식) | 사용자 Drive `2023년 OPIc 정기 기출 문제` 문서의 질문. 공식 기출로 확인된 것이 아님 |
| AI 생성 연습 문제 | 공개 시험 구조를 참고해 만든 연습 문항 |

OPIc 재응시 규칙은 공식 시험관리규정 제5조를 따릅니다(응시일 제외 25일 제한, D+26부터 응시 가능, Waiver 150일마다 1회). 규정에 없는 내용(접수 시 Waiver 자동 적용, 취소·결시 시 Waiver 복구)과 SAIL 사내 규정은 "미검증"으로 표시합니다. 날짜는 규정상 응시 가능일이며 실제 회차 조회 결과가 아닙니다.

### 4.5 Android 대응

- Android 13+ 알림 권한 런타임 요청, 거부 시 홈 배너로 대체.
- 정확한 알람: `USE_EXACT_ALARM`(33+) / `SCHEDULE_EXACT_ALARM`(≤32) → `setAlarmClock`. 권한이 없으면 `setAndAllowWhileIdle`로 대체하고 설정에 경고. 삼성 배터리 최적화 안내.
- 재부팅·앱 업데이트·시간 변경·정확 알람 권한 변경 시 `BootReceiver`가 재예약.
- 알림 액션: 지금 시작 / 바로 말하기 / 10분 후(스누즈). 저녁 리마인더는 WorkManager(목표 미달일 때만).
- 앱이 백그라운드로 가면 녹음을 즉시 멈추고 지금까지의 답변을 분석합니다(마이크를 열어 두지 않음).
- 녹음 파일은 보관 기간(기본 14일)이 지나면 자동 삭제, 설정에서 용량 확인·전체 삭제.

> Play 스토어에 올릴 경우 `USE_EXACT_ALARM`은 정책 심사 대상입니다. 현재는 개인 사이드로드 전제입니다.
